## [2026-08-22] bug | monitor.sh false "usage limit hit" auto-teardown fixed
Root-caused a repeated tmux-session crash/flap discovered during live Playwright-driven UAT verification (session died 3 times in one afternoon): `scripts/monitor.sh`'s poll loop initializes `all_idle=true`/`all_usage_hit=true` at the top of each tick, then for any agent whose pane is missing (`tmux has-session` fails), it only logged a WARN and `continue`d — never falsifying either flag. ## [2026-09-02] bug | BUG-0010 fixed — `git diff <base>` replaces `git diff <base>..HEAD`
With no active roadmap left actionable and BUG-0010 the last thing blocking TASK-071 (and thus ROADMAP-007), fixed it directly rather than leaving it open. Root cause: `GET /agents/:id/diff` (`host-server/index.ts`) used the two-ref form `git diff <base>..HEAD`, which git resolves purely commit-tree-to-commit-tree and can never read the working directory — structurally incompatible with checkpoint/rollback, which operates exclusively via `git stash` against uncommitted state. Fix: dropped `..HEAD`, so the call is now `git diff <base>` (single ref) — this compares `<base>`'s tree against the *current working tree*, capturing both committed divergence and uncommitted changes in one diff. Verified: a fresh worktree-backed fixture agent with two genuinely modified files went from `GET .../diff` returning an empty string to returning the full 1896-byte diff for both files; confirmed live in the actual browser dashboard (screenshot `tmp/bug0010-diff-panel-fixed.png`) that the "Changes" panel now renders both files' colour-coded diffs correctly. `npx tsc --noEmit` clean (one pre-existing, unrelated typing error in `capturePerfBaseline.test.ts`, confirmed untouched by this change); `npm test` 109/109 pass. `tsx watch` auto-restarted the live host-server on the file change, so the fix is live in the running dev server. Left `status: in-progress` (not `closed`) matching BUG-0004/BUG-0006's precedent on this same route file — closing is gated on a regression test, and `host-server/index.ts`'s route handlers have no HTTP-level test harness to extend.
