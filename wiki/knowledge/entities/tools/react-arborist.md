# react-arborist

Batteries-included React tree view: virtualized rendering, keyboard navigation, `searchTerm` filtering, a custom node renderer, and `rowHeight`/`height`/`indent` props. v3.16.0 (npm modified 2026-07-25), peer `react >= 16.14`, so React 19 is within range. It also ships drag-and-drop, rename and create handlers that a read-only file tree does not need, and one community commenter reports it is "somewhat painful to customize" (opinion). Fallback choice if `[[headless-tree]]` disappoints, per `[[project-file-tree]]`.
